# 龍延宮工作平台・線上儀表板

網站：https://a0981755429-debug.github.io/longyan-dashboard/

- 每 30 分鐘自動從 Google 試算表（01–06）讀取資料並重新發布；改試算表就好，不用改這裡。
- 本倉庫只放網站程式，**不放任何資料**。試算表 CSV 只在發布時抓取，不會存進 Git 紀錄。
- 網站設定不被搜尋引擎收錄（robots.txt、noindex），但知道網址的人都看得到，請勿在試算表放個資。
- 規劃、待辦卡、小龍程式在私人倉庫 `longyan-platform`。

| 檔案 | 用途 |
|---|---|
| `index.html` | 網站本體 |
| `scripts/build.py` | 讀取試算表、組成網站 |
| `scripts/ics.py` | 產生 `calendar.ics`（手機行事曆訂閱檔） |
| `.github/workflows/deploy.yml` | 自動發布排程 |
| `workflow.json` | 活動流程（整理自 LINE 群組紀錄） |
| `announcements.json` | 回宮工作公告排程 |
| `github.json` | GitHub 規劃區塊資料 |
| `templates.json` | 小編發文中心的範本（含「小編口吻」8 種骨架） |
| `voice.json` | 小編口吻規則；「複製給 ChatGPT 的修改指令」會帶入 |
| `小編口吻指南.md` | 口吻指南全文（整理自祭祀組群組公告，不含人名） |

## 訂閱到 iPhone 行事曆

訂閱網址：`https://a0981755429-debug.github.io/longyan-dashboard/calendar.ics`

- 內容：網站行事月曆的全部行程：03 年度行事曆、05 大型活動（每個工作階段）、06 農曆祭典、02 未完成待辦、04 申辦到期、09 公文期限、公告排程。同一活動代碼 03／05 都有時以 05 為準；同日同名只留一筆。
- 未完成的行程在前一天上午 9:00 提醒（公告排程不提醒）；已完成的標「✓」不提醒；取消的不列。06 有時間（如 22:00）的排在該時間。
- 只用網站已公開、已遮蔽的資料，備註欄不放進行事曆。
- iPhone：設定 → App → 行事曆 → 行事曆帳號 → 加入帳號 → 其他 → 加入已訂閱的行事曆 → 貼上網址 → 下一步 →（若要保留提醒，把「移除提示」關掉）→ 儲存。
  或在 iPhone Safari 開網站，點右上「📅 訂閱到手機」。
- Google 日曆：電腦版 → 其他日曆「＋」→ 透過網址新增。
